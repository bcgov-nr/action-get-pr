# Get PR Number

> [!NOTE]
> **Planned Deprecation**
>
> This action will be deprecated in a future release. Please transition to [`bcgov/actions/image-tracker`](https://github.com/bcgov/actions/tree/main/image-tracker).
>
> In addition to resolving the PR number (`steps.<step_id>.outputs.pr`), `image-tracker` resolves immutable image digests and commit hashes. Using immutable digests rather than mutable PR tags ensures deployments are reproducible, tamper-proof, and safer across environments.
